Entry for the [make.fun bounty](https://make.fun/bounty/the-plan-make-fun-will-carry-20261122-2138):
a plan an AI agent can carry out itself to turn $100 into the most money
in 30 days.

`main.py` (Python 3.13, standard library only, deterministic, no network)
writes the plan — 279 characters — to `/output/entry.txt`.

## The plan

> Day 1: message 50 Etsy shops/day with weak photos, offering 10 AI-enhanced
> listing photos for $15 via PayPal. Deliver same day with free tools.
> Day 3: open a $29 '30 photos in 24h' Fiverr gig, $5/day ads. Upsell
> $49/mo refresh. Reinvest in ads. Expect 25 orders, $450+ by day 30.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set).
